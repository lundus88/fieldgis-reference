# LOM P6.3 Pursuit Intelligence

Status: DEVELOPMENT / NON-PRODUCTION.

Purpose: evaluate whether an opportunity has enough evidence to move from discovery into a human-reviewed pursuit state.

Required evidence dimensions are target identity, scope, economic fit, deadline/status, eligibility, and intent. Missing critical evidence fails closed to HOLD. Historical market proof remains WATCHLIST. Actual outreach, bids, quotations, pricing commitments, contracts, production changes, and protected-main merges remain HUMAN_ONLY.

Live opportunity facts are not stored in this module unless their write path is explicitly permitted; the engine accepts evidence-bound records as input.
