## B. Isolated logical backup / restore drill

The available Supabase DEV branch price was verified on 2026-10-05 as **USD 0.01344/hour**. A new paid branch requires explicit cost approval before creation.

Scope is deliberately limited to non-sensitive control-plane configuration:

- `public.builder_registry`
- `public.builder_certification_policies`
- `public.vl_cert_health`

Drill:

1. Generate a fresh canonical JSON snapshot and SHA-256 digest per selected table from Production.
2. Record snapshot timestamp and row count.
3. Create a temporary isolated Supabase DEV branch.
4. In the branch only, create `restore_drill` clone tables using the Production table row types.
5. Restore the snapshot rows into the clone tables.
6. Recompute canonical JSON digests and row counts.
7. Require exact digest/count equality.
8. Run Supabase security and performance advisors.
9. Drop only the temporary `restore_drill` schema if desired, then delete the DEV branch.
10. Record elapsed drill time as measured RTO evidence.

This proves an application-level logical restore path for selected control-plane configuration. It **does not** claim provider PITR or physical-backup recovery.
