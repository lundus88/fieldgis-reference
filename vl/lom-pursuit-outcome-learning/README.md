# LOM P6.6 — Pursuit Outcome & Learning Loop

This module converts evidence-backed pursuit outcomes into bounded learning records.

Allowed outcome states: `WON`, `LOST`, `NO_BID`, `HOLD`, `MONITOR`.

The module is recommendation-only. It may surface lessons and proposed scoring-policy changes, but it never applies scoring weights, thresholds, authority, pricing, contracting, customer outreach, production, or protected-main changes.

Missing evidence fails closed. Revenue, win probability, loss reasons, client feedback, and commercial outcomes must never be fabricated.
