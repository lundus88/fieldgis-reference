What the states mean

Queued / Planning / Building: your request is still in the build pipeline.

Validating: build output exists and automated QA/release validation is running.

Waiting approval: automated checks reached the human production-approval boundary. No browser action can bypass it.

Failed: the run stopped fail-closed. Review the explanation shown below and submit a support request from the Pilot Portal if you need a governed retry.

Succeeded / Certified: this does not mean production was deployed. Production still requires explicit human approval and immutable promotion.
