# LOM High-Value Absorption Engine (HVAE) P0

Status: NON-PRODUCTION / GOVERNANCE CAPABILITY

HVAE is not a standalone product or a second self-improvement engine. It is a shared governance/intelligence capability that decides how new ideas, technologies, research, competitor patterns and operational lessons should be absorbed into LOM.

Canonical flow:

`Source -> Understand -> Value Extraction -> Evidence Validation -> Duplicate Detection -> Architecture Classification -> Impact/Risk -> Integration Plan -> Controlled Absorption -> Measurement -> Keep/Refine/Rollback`

Core rule:

`Novel != Valuable. Valuable != Necessary. Necessary != New Module.`

HVAE must prefer reuse and extension before any new build. A new module is allowed only when a proven gap has distinct domain rules, lifecycle and data ownership.

Authority remains unchanged:
- protected-main merge: HUMAN_ONLY
- Production release/deploy: HUMAN_ONLY
- authority widening: HUMAN_ONLY
- financial/legal/customer commitments: HUMAN_ONLY
- autonomous ceiling: PREPARE_PR
- self-approval: FORBIDDEN

HVAE composes existing LOM capability registry, Knowledge Foundation, CAIE/improvement controls, independent QA, evidence/provenance and human approval gates. It does not replace them.
