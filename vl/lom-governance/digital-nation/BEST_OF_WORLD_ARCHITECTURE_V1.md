Status: DRAFT / NON-PRODUCTION  
Date: 2026-09-29  
Owner: LOM Core Governance + LOM Intelligence + HVAE

## Official principle

LOM Virtual Nation will not copy any country as a complete model.

Instead, LOM uses **BEST-OF-WORLD ARCHITECTURE**:

**Learn from everyone. Copy no one blindly. Keep what works. Reject what fails. Integrate what creates value. Improve continuously.**

Country examples are treated as benchmark sources for particular capabilities, not as complete templates to emulate.

## Standard absorption flow

Global Benchmark
→ Extract Fundamental
→ Evidence Check
→ Compare Trade-offs
→ Remove Duplication
→ Adapt to Virtual Nation
→ Security Review

→ Integrate

This flow composes the existing LOM High-Value Absorption Engine (HVAE) rather than creating a duplicate research/absorption engine.

## Mandatory decision criteria

Every candidate fundamental must be assessed against:

1. Evidence
2. Compatibility with LOM architecture
3. Risk
4. Value creation
5. Scalability
6. Auditability
7. Security impact
8. Legal/regulatory boundary
9. Economic sustainability
10. Governance compatibility
11. Duplication/overlap
12. Reversibility and exit cost

A famous country, institution or company is never sufficient evidence by itself.

## Benchmark-unit rule

LOM benchmarks **capabilities**, not countries as whole systems.

Valid question:
- What evidence-backed design patterns improve digital identity interoperability?

Invalid question:
- Which country should LOM copy?

The matrix therefore records:
- capability pattern;
- implementation context;
- evidence;
- observed trade-offs;
- dependencies;
- conditions for success;
- risks;
- LOM compatibility;
- proposed adaptation;
- review status.

## No overall political ranking

The Global Nation Benchmark must not produce:
- an overall country score;
- a country winner;
- a political-system ranking;
- a recommendation that LOM copy a whole national political system.

It may compare documented performance or institutional design for a specific capability when the time period, population, source and limitations are recorded.

## Evidence hierarchy

Preferred evidence order:
1. primary/official administrative or statistical source;
2. multilateral datasets and methodology reports;
3. peer-reviewed research;
4. reputable independent research;
5. case-study evidence;
6. expert/community evidence only as supplementary context.

A benchmark record should normally have at least one primary/official or multilateral source before absorption.

## Output

Approved benchmark findings should produce one of four outcomes:

- **ABSORB** — reuse/adapt into an existing LOM owner.
- **PILOT** — controlled experiment before adoption.
- **REFERENCE_ONLY** — useful knowledge but no current integration.
- **REJECT** — poor fit, excessive risk, duplication, weak evidence or unacceptable trade-off.

Production activation remains separately human-gated.
