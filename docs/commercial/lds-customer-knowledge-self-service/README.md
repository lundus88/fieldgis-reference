# LD Customer Knowledge & Self-Service Center v1

Status: DEVELOPMENT / NON-PRODUCTION

Purpose: reduce repetitive support and improve customer adoption through evidence-backed, version-aware self-service documentation.

## Article types

- Getting Started
- How To
- Troubleshooting
- Known Limitation
- FAQ
- Support Path
- Change Request Path
- Handover Reference

## Evidence discipline

Every article has:
- product/project scope
- version
- owner
- last verified date
- evidence reference
- visibility classification

An article is not shown as current if the version mismatches or supporting evidence is stale/unverified.

## Safety

Self-service never replaces:
- security incident escalation;
- P0 incident handling;
- customer-specific support where human intervention is required;
- governed Change Request;
- handover/ownership source of truth.

Known limitations remain explicit.
