# LD Executive Commercial Mission Control v1

Status: DEVELOPMENT / NON-PRODUCTION
Mode: READ-ONLY EXECUTIVE COMPOSITION

Purpose: give LD one executive commercial view across pipeline, revenue, margin, capacity, customer health, recurring revenue and risk without creating another source of truth.

## Relationship to LOM Mission Control

LOM Mission Control remains the operational/project truth and governance control surface. LD Executive Commercial Mission Control consumes commercial ledgers plus LOM project truth for business interpretation only.

It does not create project state, commercial commitments or execution authority.

## Evidence discipline

Every metric exposes:
- source status;
- freshness;
- evidence completeness;
- resulting CONFIRMED / REVIEW / HOLD state.

A dashboard number is never treated as confirmed simply because it can be calculated.

Examples:
- revenue requires authoritative paid-order evidence;
- margin requires current cost inputs;
- customer health does not treat no complaint as satisfaction;
- recurring revenue requires active customer-accepted support/maintenance commitment.

## Authority boundary

This dashboard has no customer outreach, quotation, pricing, payment, scope, merge or Production deployment authority.
