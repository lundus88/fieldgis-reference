# LD Handover & Exit Package v1

Status: DEVELOPMENT / NON-PRODUCTION

Purpose: make project handover and customer exit explicit, portable and auditable.

## Package contents

- deliverables inventory
- source/artifact inventory
- deployment targets
- domains/DNS
- databases and export evidence
- third-party accounts/subscriptions
- credential transfer plan
- technical/user documentation
- known limitations
- support/warranty boundary
- ownership/licensing statement
- access revocation plan
- customer acceptance
- final evidence manifest

## Ownership and portability

Customer-owned assets should end in customer-controlled accounts where practical and contractually agreed. LD must not create avoidable lock-in by leaving essential assets solely under an LD staff account.

## Credential security

Passwords, API keys and other secrets are never copied into ordinary PDF/Markdown handover packs. A secure approved transfer mechanism is used, followed by rotation/revocation where appropriate.

## Exit completion

HANDOVER_COMPLETE requires:
1. explicit customer acceptance;
2. access-revocation evidence;
3. complete final evidence manifest.

No Production activation is authorized by this package.
