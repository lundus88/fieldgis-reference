# LD Delivery Benchmark & Learning Engine v1

Status: DEVELOPMENT / NON-PRODUCTION

Purpose: learn from completed projects so future ETA, pricing and capacity planning become more accurate.

## Metrics

- first visible progress
- total delivery cycle
- internal cost
- rework
- support burden
- customer dependency delay
- UAT cycle

## Evidence discipline

Benchmarks are grouped by comparable project class. Small samples do not create confident recommendations.

Output shows spread:
- minimum
- median
- maximum

This avoids pretending that one historical average is a guaranteed future delivery time.

## Important separation

Customer dependency delay is tracked separately from internal delivery cycle. Internal rework and regressions remain visible rather than being hidden from learning data.

## Authority boundary

Benchmark evidence may inform:
- Pricing Intelligence
- Capacity planning
- System Blueprint estimates
- executive reporting

It cannot:
- overwrite an approved ETA;
- change an approved quotation;
- change scope;
- create a customer promise automatically;
- authorize Production.
