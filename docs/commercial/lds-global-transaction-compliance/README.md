# LD Global Transaction Compliance Engine v1

Status: DEVELOPMENT / NON-PRODUCTION

Purpose: determine whether a proposed cross-border transaction is sufficiently evidenced for human commercial review without inventing tax, FX, sanctions, or regulatory conclusions.

Flow:
Customer Country → Supported Market → Currency Evidence → Tax Evidence → Compliance Evidence → Human Commercial Review

Rules:
- no automatic tax advice;
- no automatic legal/regulatory conclusion;
- no invented FX rate;
- no customer charge;
- unsupported or stale evidence returns REVIEW/HOLD;
- final commercial and compliance approval remains human-gated.
