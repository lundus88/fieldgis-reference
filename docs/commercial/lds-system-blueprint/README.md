# LD System Blueprint / Paid Discovery v1

Status: DEVELOPMENT / NON-PRODUCTION

Purpose: bridge the gap between Workflow Assessment and Quotation.

Flow:
Workflow Assessment → Qualification → System Blueprint → Customer Review → Scope Snapshot → Quotation

## Blueprint contents
Problem, current workflow, proposed workflow, user roles, modules, integrations, dependencies, assumptions, out-of-scope items, acceptance criteria, milestones, risks and open questions.

## Two modes
- LIGHTWEIGHT_FREE: concise problem/solution/scope direction only.
- PAID_DISCOVERY: deeper planning for complex projects after commercial authorisation.

## Boundaries
Blueprint approval does not start a build and does not create a binding price. Quote and build authority remain separate.

Once the customer approves a scope snapshot, that version is immutable. Any material change must go through Change Request.
