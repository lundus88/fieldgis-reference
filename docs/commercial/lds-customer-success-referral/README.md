# LD Customer Success / Testimonial / Referral Engine v1

Status: DEVELOPMENT / NON-PRODUCTION

Purpose: turn genuine customer success into trustworthy social proof and referrals without assuming satisfaction or pressuring customers.

## Flow

DELIVERY EVIDENCE
→ ACCEPTANCE EVIDENCE
→ SATISFACTION CHECK
→ SATISFACTION CONFIRMED
→ TESTIMONIAL / REFERRAL ELIGIBILITY

## Core rules

- no complaint is not proof of satisfaction;
- unresolved issues route to follow-up first;
- testimonial publication requires explicit permission;
- referral requests happen only after success evidence;
- referral contacts are not auto-contacted;
- testimonial wording remains customer-approved;
- incentives require separate approval/disclosure.

This module prepares eligibility and next action only. It does not publish testimonials or contact referrals automatically.
